# Direct Campaign Manager

Веб-приложение для подготовки рекламных проектов Яндекс Директа через Click.ru API. Сейчас это безопасный стартовый каркас: настройки режима кампаний, защищённый интерфейс, хранение настроек в SQLite и проверка подключения к Click.ru. Создание рекламных кампаний и цели Метрики не запускаются автоматически, пока не будут проверены схемы запросов и доступы на тестовом аккаунте.

## Режим кампаний

В настройках проекта доступны два варианта:

- **Отдельные кампании** — одна кампания для Поиска и одна для РСЯ.
- **Одна ЕПК** — одна Единая перфоманс-кампания с включёнными местами показа Поиск и Рекламная сеть Яндекса.

Настройка сохраняется для каждого проекта. Это именно выбор шаблона создания, а не переключатель мест показа для уже существующих кампаний.

## Стек

- Python 3.12
- FastAPI + Uvicorn
- SQLite для начального развёртывания
- HTTPX для Click.ru API
- Защита интерфейса через HTTP Basic Auth

## Запуск локально или на сервере

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# Заполните .env уникальным паролем администратора и токеном Click.ru
uvicorn --env-file .env app.main:app --host "${APP_HOST:-127.0.0.1}" --port "${APP_PORT:-8000}"
```

Откройте `http://127.0.0.1:8000`. Не публикуйте приложение в интернет без HTTPS и уникального пароля администратора. Для внешнего доступа используйте reverse proxy с TLS.

В Docker:

```bash
docker compose up --build -d
```

## Переменные окружения

Смотрите `.env.example`. Реальный `.env` намеренно исключён из Git. Не вставляйте секреты в исходный код, коммиты, скриншоты или логи.

## Click.ru API

Базовый URL: `https://api.click.ru`. Документация и Swagger: https://api.click.ru/V0/docs/

Приложение использует:
- `GET /V0/user` — проверка токена;
- `GET /V0/integrations` — список подключённых интеграций;
- `GET /V0/accounts` — список рекламных аккаунтов;
- `POST /V0/accounts` — создание Direct-аккаунта с выбранной подключённой интеграцией Яндекс ID;
- `GET /V0/stat` — запрос статистики Click.ru (после выбора периода и аккаунтов).

Лимиты API и права доступа определяются Click.ru. Приложение не создаёт почтовые аккаунты Яндекса и не обходит этап подключения/авторизации Яндекс ID в Click.ru.

## Что уже подключено и что осталось

Уже реализованы проверка токена Click.ru, список подключённых интеграций/аккаунтов и явное создание Direct-аккаунта через `POST /accounts` с выбором `integrationId`. До использования с боевыми доступами сначала проверьте результат на тестовом аккаунте.

1. Создание/выбор счётчика Метрики, создание JavaScript-цели `lead` и проверка установки счётчика на сайте.
2. Сборка ЕПК/отдельных кампаний, групп, объявлений и изображений через Click.ru API-прокси для Яндекс Директа.
3. Отчёт по конверсиям `lead` через Reports API Директа; согласование НДС и атрибуции с расходами Click.ru.
4. Очередь фоновых заданий, идемпотентность, проверка дублей и подробный журнал выполнения.

Кампаниям и настройкам целей нужна отдельная проверка API-схем на тестовом аккаунте. Приложение пока не публикует объявления, не включает кампании и не расходует рекламный бюджет.

## Секреты

Если токен ранее был отправлен в переписку или иначе мог стать доступным третьим лицам, перевыпустите его в Click.ru и используйте только новый токен в серверном `.env`.
